Studio Dashboard Inventory

Inventory a Dashboard Studio dashboard

Paste the dashboard source, or drop or choose a file. The tool lists every tab, input, data source, search, chain search, visualization and token, and shows how they connect.

Everything runs in this page. Nothing is uploaded or saved.

How to get the dashboard source
  1. From the Splunk UI: open the dashboard, click Edit, then Source (</>), and copy the JSON.
  2. From the app folder: $SPLUNK_HOME/etc/apps/<app>/local/data/ui/views/<dashboard>.xml (or default/). Paste the whole XML file.
  3. From the REST API: curl -k -u user "https://splunk:8089/servicesNS/-/<app>/data/ui/views/<dashboard>?output_mode=json", then paste the response.

This tool reads Dashboard Studio dashboards (version="2"). Classic Simple XML dashboards have no Studio definition, so they are not supported.
