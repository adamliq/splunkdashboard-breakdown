Studio Dashboard Inventory

Inventory a Splunk dashboard

Paste the dashboard source, or drop or choose one or more files. The tool lists every tab, input, data source, search, chain search, visualization and token, shows how they connect, and checks for problems. Dashboard Studio and Classic Simple XML are both supported. Load several files, or a REST list of views, to inventory a whole app.

Everything runs in this page. Nothing is uploaded or saved.

Splunk configuration (optional): macros, saved searches, data models

Paste macros.conf and savedsearches.conf, and data model JSON, so the page can look inside macros, saved searches and data models. You can also add or change these later on the Splunk config page.

How to get the dashboard source
  1. From the Splunk UI: open the dashboard, click Edit, then Source (</>), and copy the JSON.
  2. From the app folder: $SPLUNK_HOME/etc/apps/<app>/local/data/ui/views/<dashboard>.xml (or default/). Paste the whole XML file.
  3. From the REST API: curl -k -u user "https://splunk:8089/servicesNS/-/<app>/data/ui/views/<dashboard>?output_mode=json", then paste the response.

Dashboard Studio dashboards are read as they are. Classic Simple XML dashboards (<dashboard> or <form>) are converted to the Studio model first, so their layout is approximate. A REST response listing many views loads them all.

Share this dashboard as a link

The link holds the whole dashboard definition, compressed, after the #. Opening it loads the dashboard in Studio Dashboard Inventory. That part of a link is never sent to a web server, but anyone you give the link to can read the definition, including its searches.
